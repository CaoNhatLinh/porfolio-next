# Portfolio review — 2026-10-03

## Scope and outcome

Reviewed public discovery, featured/archive behavior, bilingual forms, owner authorization, content mapping, contact delivery, media uploads, analytics and Capsem interactions. This is a local implementation review, not certification of a live Supabase/Vercel deployment.

## Corrected

- Contact success now requires persistence. Missing credentials/database failures return 503; provider notification failures do not discard a saved message. Network failures retain entered form values.
- Contact rate limiting moved from process memory to an atomic Supabase function: five attempts per hour, shared across Vercel instances, keyed hashes instead of raw IPs.
- Configured CMS with zero published records returns an empty collection, not resurrected fixtures. New records no longer inherit an unrelated project's narrative. Explicitly cleared sections and optional translations remain cleared.
- All-project archive includes featured projects. A normal project is no longer implicitly labelled featured. Empty filters do not remove the filter controls.
- Article topics come from published data, topic links are URL-encoded and empty results are explained.
- Sitemap uses the public repository. Project/article changes invalidate home, listing/detail routes and sitemap; profile changes invalidate contact too.
- Optional team context/response time can be blank. Social/external links accept HTTP(S), not arbitrary schemes; internal proof links exclude protocol-relative URLs.
- Profile lookup errors cannot silently trigger an insert.
- Published admin Lab records are now rendered on About alongside the built-in interactive experiment.
- Mobile language switch is visible. Document language follows the selected locale after hydration. Mobile menu supports Escape/focus return.
- Capsem keyboard activation survives initial loading. Closing stops remaining inertia; Escape closes from elsewhere and returns focus.
- Uploaded storage object is cleaned up if metadata persistence fails.
- Analytics uses a view UUID so engagement updates do not create additional page views after 45 seconds. SPA navigation flushes engagement; hidden-tab time is excluded. Preview routes are excluded. Queries paginate rather than silently truncate at 10k/50k. Period unique metric is explicitly visitor-days.
- Existing gallery effect lint error and dialog description warning corrected. Regression tests added for CMS and contact delivery.

## Remaining improvements / limitations

- Admin quick-action wrappers currently discard ActionResult errors; these controls should reuse the existing ActionForm error/pending state. Archive dialog should stay open on failed actions.
- Admin loaders often treat backend errors as empty lists. Separate configuration/load failures from genuine empty states.
- Article publication timestamp is reset by republishing; preserve first publication date if that is the intended editorial rule.
- Admin inbox only loads the latest 50 messages; add pagination/filtering before volume grows.
- Image URLs need validation against the Next Image allowlist; editable imageFit and article cover alt/caption are not persisted yet.
- Some resume/home text is code-managed rather than CMS-managed. Publishing all information from the admin requires extending those editors/schema, not merely adding a UI library.
- Locale document attribute is corrected client-side; locale-prefixed routing would support server-rendered language and localized metadata more fully.
- Analytics engagement upserts can arrive out of order; an SQL update using greatest(engaged_ms) would prevent smaller late payloads replacing larger values. Legacy events still use the older deduplication path.
- Three admin/preview native-img lint warnings remain. React Three Fiber emits a Three.Clock dependency deprecation warning. Capsem is an approximate original model, not a scan of the physical product.

## Library strategy

Reuse Radix for accessible interaction primitives, React Hook Form/Zod for form state and boundaries, Motion for gestures/transitions, Embla for galleries, Recharts for admin graphs and Supabase SDK/Resend for their services. Add packages only for identified gaps: Tiptap for rich content editing, TanStack Table for larger admin lists, Drei for GLTF/scene helpers. A library does not replace owner authorization, data truth, delivery semantics or a properly modelled GLB.
