## V3 multi-page direction

V3 replaces the one-page structure with dedicated routes and gives each page a different editorial rhythm:

- `homepage-v3-art-direction.png`: focused brand introduction and one featured-work teaser.
- `work-index-v3.png`: gallery-like project archive with featured work first.
- `project-case-study-v3.png`: cinematic engineering case study.
- `about-lab-v3.png`: personal story, experience, tools, and experiments.
- `journal-v3.png`: technical writing archive and newsletter.
- `contact-v3.png`: immersive contact page with an integrated project form.

Suggested routes:

- `/`
- `/work`
- `/work/[slug]`
- `/about`
- `/journal`
- `/journal/[slug]`
- `/contact`
- `/admin`

V3 deliberately varies page composition. Shared typography, materials, navigation, and the acid-lime accent provide continuity without forcing every page into the same grid.

Design system:

- Graphite near-black surfaces with cool silver typography.
- One restrained acid-lime accent.
- Sans display typography supported by mono details.
- 16px public-page corners and 12px admin controls.
- Thin orbital geometry carried forward from the Laravel references.
- Responsive layouts should reflow, not shrink desktop content.
