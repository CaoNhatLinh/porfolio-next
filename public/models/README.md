# Gaim Capsem 3D model

`gaim-capsem.glb` is a project-owned binary glTF asset generated by
`scripts/generate-gaim-capsem-model.mjs`. It contains the mesh geometry and PBR
materials used by the interactive Three.js scene.

The shape is an original low-poly interpretation made for this portfolio. It
is inspired by the physical proportions of Bandai's Rider Capsem product and
does not contain extracted game or toy geometry.

Regenerate it with:

```bash
npm run model:gaim
```
